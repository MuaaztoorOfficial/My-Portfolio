# Muaaz — Portfolio

A personal portfolio website for Muaaz, a web designer from Lahore, Pakistan specialising in custom, high-performance websites for local businesses.

## Features

- Hero section with bold typography and animated reveal
- Work and services showcase
- About and contact sections
- Fully responsive layout with mobile navigation
- Custom neon-green accent palette
- SVG logo branding

## Tech

HTML, CSS, JavaScript
